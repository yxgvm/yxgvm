## 💻 Мои проекты

### [TelegramGiftsAnalyzer](https://github.com/yxgvm/TelegramGiftsAnalyzer)
*Автоматизированный анализ рынка Telegram*
- **Что сделано:** Реализована логика агрегации разрозненных записей о продажах в единую структуру с последующим экспортом в Excel для пользователей.
- **Ценность:** Автоматизация формирования отчетности по продажам цифровых активов, исключающая ручной сбор и минимизирующая риск потери данных при интеграции.

*Автоматизация сбора данных*
