## 💻 Мои проекты

### [TelegramGiftsAnalyzer](https://github.com/yxgvm/TelegramGiftsAnalyzer)
*Анализ интеграций и проектирование отчетности*
- **Что сделано:** Изучены методы взаимодействия с Telegram для извлечения транзакционных данных. Реализована логика агрегации разрозненных записей о продажах в единую структуру с последующим экспортом в Excel для пользователей.
- **Ценность:** Автоматизация формирования отчетности по продажам цифровых активов, исключающая ручной сбор и минимизирующая риск потери данных при интеграции.

### [HHVacancyTracker](https://github.com/yxgvm/HHVacancyTracker)
*Системный анализ и автоматизация сбора данных*
- **Что сделано:** Проведен анализ API hh.ru, спроектирована модель данных для хранения вакансий и реализован парсер.
- **Ценность:** Перевод сырого потока данных из внешнего API в структурированный текстовый отчет и расчет ключевых рыночных метрик в реальном времени.
